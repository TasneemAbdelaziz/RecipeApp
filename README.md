# Recipe App
A new Flutter project.

The main aim of this app is not just giving you instructions to cook a meal nor its ingredients only 
It also provides you with the estimated time, servings size and also provide similar recipes from 
Spooncular API based on your choices with functionalities to search through many recipe through 
an interactive search bar by searchDelegate provided by flutter. You can also add your favorite 
recipes, choose your desired application theming from light mode or dark mode and save/edit
your personal information via Firebase Authentication, Firebase Firestore, Provider and Shared 
Preferences.
